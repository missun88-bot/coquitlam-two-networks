# OpenStreetMap data and licences

The road and pedestrian geometry/attributes in `data/vehicles.js` and
`data/walking.js` originate from **OpenStreetMap contributors**. They were
retrieved through QuickOSM/QGIS and exported through qgis2web, with unused
attributes removed to reduce file size. Feature geometries and available `name`
and `highway` values were preserved.

shown only where OSM provides them; absence of a name does not prove that a
road or trail is unnamed in reality.

The visualization, layout and explanatory narrative are the creative work of
**Iris Sun**. No blanket licence is granted here for the original site code or
written content. The external map libraries retain their own licences (see
`THIRD_PARTY_NOTICES.md`).

This is an artistic and exploratory comparison of mapped networks, not a
routing engine or measured accessibility/travel-time analysis. The pedestrian
network is not a complete inventory of sidewalks or walking connections.
